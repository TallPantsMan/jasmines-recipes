# Jasmine's Recipes 🍳

A modern, subscription-free recipe management PWA inspired by ReciMe.

## Features
- **All Sources in One Place:** Scrape recipe websites (JSON-LD), auto-organize Instagram Reel captions, and scan physical cookbook pages using on-device OCR.
- **Orientation-Adaptive:** Optimized for both landscape (countertop stand split-view with persistent ingredients checklist) and portrait handheld cooking.
- **ReciMe Design Language:** Cheerful ReciMe Tangerine Orange (#FF5B26), vanilla cream (#FDFBF7), Fraunces editorial typography, and rounded tactile cards.
- **Want to Try:** Dedicated queue for recipes Jasmine wants to cook next, with live filter counters.
- **Jasmine's Notes:** Cozy recipe diary to jot down tweaks, adjustments, and family ratings.
- **Photo Gallery:** Capture finished dish photos alongside original recipe images.
- **100% Free & Private:** IndexedDB local storage with instant JSON backup & restore.
